    Cara import ke Alight Motion
    1. Unduh file dari tombol di bawah. Jika hasilnya ZIP, ekstrak dulu sampai ada file .xml.
    2. Buka Alight Motion, ketuk tombol + lalu pilih Import.
    3. Pilih file .xml. Proyek baru muncul dengan nama yang kamu isi, berisi layer hasil trace.
    4. Kalau posisi gambar bergeser, ubah Titik asal koordinat path lalu unduh ulang.
